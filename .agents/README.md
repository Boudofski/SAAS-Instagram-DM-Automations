# AP3K marketing workflows

Corey Haines marketing skills are installed as a pinned, MIT-licensed Git submodule at `marketingskills`. `skills` points to its discovery directory.

After cloning, run `git submodule update --init --recursive`. Updates are explicit: review upstream changes and commit the new gitlink; do not silently track latest.

Read `product-marketing.md` first. Select the workflow relevant to the task, inspect existing work, and verify claims against product code and observed results. Installation does not authorize sending campaigns, buying ads, or inventing testimonials. Preserve locale support, consent, pricing contracts and existing tracking.
